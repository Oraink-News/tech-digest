#### 1. HTTP2Shell 再扩容：不止 Node.js 中招

看雪学院披露，HTTP2Shell 根源坐实为 Brotli 解码器越界写：可脱离 HTTP 链路触发，.NET、ClickHouse、FFmpeg、Apache Arrow 相继落入射程。三天前业界还按「给 Node.js 打补丁」收口，如今这条修补路线被证明存在大面积漏检。漏洞不住在应用里，而住在被无数项目静态嵌入的底层库里；排查逻辑得从「装没装 Node」换成「哪里链了 Brotli」。
